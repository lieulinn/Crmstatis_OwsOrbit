# OWS CRM

Dashboard Customer Relationship Management sederhana menggunakan HTML5, CSS3, dan Vanilla JavaScript.

## Fitur
- Dashboard statistik dan visualisasi penjualan
- CRUD pelanggan (tambah, edit, hapus belum langsung tersedia sebagai tombol khusus hapus; edit tersedia melalui menu titik-titik)
- Pipeline penjualan dengan perpindahan tahap
- Agenda aktivitas dan checklist follow-up
- Laporan ringkas dan ekspor CSV
- Backup data JSON
- Mode gelap
- Data tersimpan di browser menggunakan localStorage
- Responsif untuk desktop, tablet, dan mobile

## Menjalankan secara lokal
1. Ekstrak ZIP project.
2. Buka folder `business-crm` di VS Code.
3. Klik kanan `index.html` lalu pilih **Open with Live Server**. Jika Live Server belum tersedia, pasang ekstensi Live Server atau buka `index.html` langsung di browser.

## Catatan
Project ini merupakan demo frontend. Data hanya tersimpan pada browser/perangkat yang digunakan. Belum ada login sungguhan, sinkronisasi cloud, atau database server. Jangan gunakan data pelanggan sensitif sebelum backend dan keamanan ditambahkan.
